# Patrick Sales — AI Automation Portfolio

A single-page portfolio site showcasing production AI automation systems I've built for lead response, voice reception, customer support, invoicing, and CRM operations.

**🌐 Live site:** https://patrick-portfolio-psi.vercel.app

---

## What's inside

Six real, production-grade builds — each presented as **Problem → Solution → Stack → Impact** with a screenshot of the actual workflow behind it:

| Build | What it does |
|---|---|
| ⚡ Speed-to-Lead Responder | Replies to new leads in under 60 seconds (Make + Zapier + Airtable) |
| 📞 AI Voice Receptionist | Answers, books, routes, and escalates calls 24/7 (Vapi + Twilio + n8n) |
| 📧 AI Email Support Agent | Reads, drafts, categorizes, and escalates the tricky ones |
| 💸 AR Autopilot | Chases overdue invoices + a weekly cash-flow brief (Xero) |
| 🧠 RAG Support Chatbot | 24/7 answers grounded in your own docs |
| 🔧 CRM Lead Engine | Enriches, scores, and cleans your pipeline automatically |

Every system ships with error handling, human hand-off, and reporting built in.

## Stack

`n8n` · `GoHighLevel` · `OpenAI` · `Vapi Voice AI` · `Twilio` · `Make / Zapier` · `Airtable` · `HubSpot` · `Xero` · `Python`

## Tech

The site itself is a single self-contained `index.html` — no build step, no dependencies. Dark theme, responsive, with scroll-reveal animations. Workflow-canvas screenshots live in `assets/`.

## Deploying

Hosted on [Vercel](https://vercel.com) with auto-deploy on push to `main`:

```bash
git commit -am "Update portfolio"
git push
```
